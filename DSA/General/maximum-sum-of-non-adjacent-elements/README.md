## 📝 Problem Statement

Given an integer array nums of size n. Return the **maximum sum** possible using the elements of nums such that no two elements taken are adjacent in nums.

### Example 1:

**Input:** nums = [1, 2, 4]

**Output:** 5

**Explanation:**

[<u>1</u>, 2, <u>4</u>], the underlined elements are taken to get the maximum sum.

### Example 2:

**Input:** nums = [2, 1, 4, 9]

**Output:** 11

**Explanation:**

[<u>2</u>, 1, 4, <u>9</u>], the underlined elements are taken to get the maximum sum.
